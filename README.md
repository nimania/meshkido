# مشکی‌دو | MeshkiDo

مرجع فارسی سریال‌های **در حال پخش ایران** — فاز اول.

**نشانی سایت پس از فعال‌سازی GitHub Pages:** https://nimania.github.io/meshkido/

## محدودهٔ فاز اول

فقط مجموعه‌های **داستانی ایرانی با قسمت‌های تازه**؛ نمایش خانگی و تلویزیون. بازپخش، مسابقه، تاک‌شو و آرشیو قدیمی فعلاً خارج‌اند.

ساختار مستقل از `nimania/meshkimedia` است. کد و داده و گردش‌کار مشکی‌دو هیچ تغییری در مشکی‌مدیا نمی‌دهند.

## معماری

- `data/series.json`: پروندهٔ سریال‌ها و شواهد پخش
- `data/updates.json`: خبرهای کوتاه مستند و لینک منبع
- `scripts/build.mjs`: تولید صفحات مستقل SEO و نقشهٔ سایت، بدون وابستگی npm
- `public/`: فونت/ظاهر/جاوااسکریپت عمومی
- `.github/workflows/pages.yml`: ساخت و انتشار GitHub Pages

ساخت محلی: `node scripts/build.mjs`؛ خروجی در `dist/`. برای انتشار، GitHub Settings → Pages → Build and deployment → Source را **GitHub Actions** انتخاب کنید. سپس Actions → Deploy MeshkiDo → Run workflow را اجرا کنید (یا commit جدید بزنید).

## اصول صحت محتوا

1. هیچ عدد بازدید یا ریتینگی بدون منبع معتبر ایجاد نمی‌شود.
2. روز هفتگی پخش، **تضمین انتشار قسمت مشخصی در آینده نیست**؛ شماره قسمت یا تاریخ انتشار جدید فقط پس از تأیید درج شود.
3. هر سریال منبع، نام پلتفرم، زمان آخرین بررسی و وضعیت مستند دارد.
4. خبرهای منابع دیگر بازنشر کامل نمی‌شوند؛ فقط توضیح فارسی اصیل با لینک به منبع.
5. با پایان پخش، وضعیت به `تمام‌شده` تغییر می‌کند؛ برای فاز اول دیگر در فهرست فعال نمایش داده نمی‌شود، ولی صفحهٔ اختصاصی حفظ می‌شود.
6. با قدیمی‌شدن منابع، سایت برچسب زمان آخرین بررسی را نمایش می‌دهد؛ «به‌روز» بدون شاهد اعلام نمی‌کند.

## به‌روزرسانی

`data/series.json` و `data/updates.json` را با خبر تأییدشده اصلاح کنید؛ commit به `main` همه صفحات را بازسازی و منتشر می‌کند. **جمع‌آوری خودکار خبر و قسمت هنوز فعال نشده است** و باید در فاز مستقل همراه کنترل کیفیت پیاده شود.
